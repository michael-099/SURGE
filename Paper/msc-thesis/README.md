# MSc Thesis LaTeX Template (AAU · AAiT · SiTE)

This is a LaTeX template for an MSc thesis at the School of Information Technology and
Engineering (SiTE), Addis Ababa Institute of Technology, Addis Ababa University.

## Build

```bash
latexmk main.tex      # or: make
latexmk -c            # or: make clean   (removes auxiliary files)
```

The build uses pdfLaTeX and **biber**. On **Overleaf**, upload the whole folder and set the
compiler to pdfLaTeX. Overleaf runs biber automatically.

## Structure

| Part | File(s) |
|---|---|
| Title page | generated by `\maketitlepage` from the details in `main.tex` |
| Approval by Board of Examiners | generated by `\makeapprovalpage` |
| Declaration | generated by `\makedeclaration` |
| Dedication (optional) | `frontmatter/dedication.tex` |
| Abstract | `frontmatter/abstract.tex` |
| Acknowledgment | `frontmatter/acknowledgment.tex` |
| Table of Contents, List of Figures, List of Tables | automatic |
| List of Acronyms | `frontmatter/acronyms.tex` |
| Chapter One: Introduction | `chapters/01-introduction.tex` |
| Chapter Two: Literature Review | `chapters/02-literature-review.tex` |
| Chapter Three: Related Work | `chapters/03-related-work.tex` |
| Chapter Four: Methodology | `chapters/04-methodology.tex` |
| Chapter Five: Experiments, Results and Discussion | `chapters/05-experiments.tex` |
| Chapter Six: Conclusion and Future Work | `chapters/06-conclusion.tex` |
| References | `references.bib` (IEEE style) |
| Appendices A, B, … | `appendices/` |

To add, remove or reorder parts, edit the `\input` lines in `main.tex`. To add another appendix,
create a file with a `\chapter{...}` in `appendices/` and `\input` it after `\appendix`.

## Getting started

1. Fill in the title, your name, advisor(s), department, degree and date at the top of `main.tex`.
   If you have no co-advisor, write `\coadvisor{}` and the co-advisor lines disappear
   everywhere.
2. **AAiT logo:** save it as `figures/aait-logo.png`. Until you do, the title page shows a
   placeholder box. The AAU logo is already included.
3. Write each chapter. Each section starts with a grey **Guide** box saying what belongs there.
   Before you submit, hide all of them with `\documentclass[noguidance]{aaitthesis}`.
4. Replace the example entries in `references.bib` with your own.

## Writing tips

- **Cite** with `\cite{key}`. The style is IEEE, and only cited works are listed.
- **Acronyms:** use `\ac{CNN}` (plural `\acp{CNN}`). The first use prints the long form.
- **Cross-references:** use `\cref{fig:...}`, `\cref{tab:...}`, `\cref{eq:...}`,
  `\cref{alg:...}` or `\cref{ch:...}`. These print "Figure 4.1", "Table 5.2", "Equation (4.1)",
  "Algorithm 4.1", "Chapter 3" and so on. Refer to every figure and table in the text.
- **Captions:** put table captions **above** the table and figure captions below the figure.
- **Examples:** Chapters 4 and 5 show figures, sub-figures, tables, equations and an algorithm.
  Copy them as needed.

## Formatting

- **Type and spacing:** 12 pt Times with 1.5 line spacing, on A4 paper.
- **Margins:** 3 cm on the left (for binding) and 2.5 cm on the other sides. Change them in the
  `geometry` line of `aaitthesis.cls`.
- **Headings:** chapters are headed "CHAPTER ONE / INTRODUCTION". Sections are numbered "1.1.",
  as in the SiTE guideline.
- **Page numbering:** preliminary pages use roman numerals and the title page has no number.
  The main text starts at page 1.

## Note on sources

The SiTE guideline in the parent folder (*Guideline for MSc Thesis Proposal Writing and
Evaluation*, 2022) covers the proposal only. This template uses its formatting rules (type size,
spacing, title page contents, numbering, IEEE references) and the matching introduction
sections. The rest follows common AAU/AAiT practice and is not set by any SiTE document:
the six-chapter outline, the approval page signatories, the declaration wording and the order of
the preliminary pages. **Check these against your school's thesis guideline or a recently
approved SiTE thesis**, and against what your advisor expects. Each of them can be changed in
`main.tex` or `aaitthesis.cls`.
